How to Compile and Run

Make sure you have GCC installed, then run these from the project folder.

terminal
# Simple Calculator
gcc simple_calculator.c -o calculator
./calculator

# Bank Management System
gcc bank_management.c -o bank
./bank

# Password Generator
gcc password_generator.c -o password
./password

On Windows, run the generated .exe files instead (for example calculator.exe). The bank program creates accounts.dat automatically the first time you add an account.
